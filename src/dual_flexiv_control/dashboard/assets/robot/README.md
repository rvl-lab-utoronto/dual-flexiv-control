# Robot-visualization assets

- `urdf/Rizon4s.urdf` — vendor URDF for this arm (committed, kept **verbatim**;
  autogenerated from `flexiv_description/urdf/rizon.urdf.xacro`, with the
  factory-calibrated joint origins). Its `<mesh filename="../meshes/...">`
  references resolve against the sibling `meshes/` directory, so don't move one
  without the other.
- `meshes/Rizon4s/` — the vendor mesh package (committed, ~3.6 MB): `visual/`
  per-link OBJ+MTL pairs (drawn in the metrics viewer's 3D robot scene; parsed by
  `robot_view._load_obj` because Rerun's OBJ loader drops MTL colours) and
  `collision/` convex STLs (not rendered; kept with the package). Vertex units
  are **metres** — the exporter's "ModelUnit: MilliMeters" comment is wrong.
- `pedestal.glb` — **generated, git-ignored** (~15 MB). The two-arm pedestal,
  converted from the Vention STEP. Regenerate with:

  ```bash
  pip install trimesh cascadio
  python -c "import trimesh; trimesh.load('VentionAssembly_509568_v26.STEP').export('pedestal.glb')"
  ```

  If `pedestal.glb` is absent the 3D robot scene still renders the two arms, just
  without the pedestal mesh. If the visual meshes are absent, the arms fall
  back to a kinematic skeleton (tubes + joint balls).
